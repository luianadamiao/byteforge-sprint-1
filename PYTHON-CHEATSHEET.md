#Python Cheatsheet

#Função
A função é uma espécie de blocos de códigos que reutilizamos, isso para deixar o código limpo. Ela serve para que não precisemos ter que reescrever a mesma linha de um código sempre que quisermos utilizar. E para isso usamo a instrução def.

#Como se importa um pacote
Um pacote é uma colecção de de módulo (que são arquivos que têm código Python, que serve par criar biblioteca). Usamos para isso a instrução "importo" ou "from".
